## ¿Qué es Git?

Git es un sistema de control de versiones distribuido, creado por Linus Torvalds (el mismo creador de Linux) en 2005. Permite rastrear cambios en el código y colaborar con otros desarrolladores.

## Comandos básicos

- `git init` — inicia un repositorio
- `git add .` — agrega cambios al área de preparación
- `git commit -m "mensaje"` — guarda los cambios
- `git push` — sube los cambios a un repositorio remoto
- `git pull` — descarga los últimos cambios

## ¿Por qué usar Git?

- **Historial completo:** puedes volver a versiones anteriores en cualquier momento.
- **Trabajo en equipo:** varias personas pueden trabajar en el mismo proyecto sin pisarse.
- **Ramas (branches):** permite probar cosas nuevas sin afectar el código principal.

## Conclusión

Git es una herramienta fundamental para cualquier programador. Junto con plataformas como GitHub o GitLab, facilita enormemente el trabajo colaborativo y el respaldo del código.
