## ¿Qué es Docker?

Docker es una plataforma que permite empaquetar aplicaciones junto con todas sus dependencias en "contenedores". Esto garantiza que el software funcione igual sin importar dónde se ejecute.

## Ventajas principales

- **Portabilidad:** funciona igual en tu PC, en un servidor o en la nube.
- **Aislamiento:** cada contenedor es independiente, sin conflictos entre aplicaciones.
- **Ligereza:** los contenedores son mucho más livianos que las máquinas virtuales tradicionales.
- **Rapidez:** se inician en segundos.

## Comandos básicos

- `docker pull imagen` — descarga una imagen
- `docker run imagen` — ejecuta un contenedor
- `docker ps` — lista contenedores activos
- `docker stop id` — detiene un contenedor

## Casos de uso

Docker se usa ampliamente para desarrollo, pruebas y despliegue de aplicaciones, especialmente en arquitecturas de microservicios.

## Conclusión

Docker simplifica enormemente el desarrollo y despliegue de software, eliminando el clásico problema de "en mi máquina sí funciona".
